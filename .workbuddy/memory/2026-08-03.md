## 修复 account-center Bean 冲突启动失败（完成）

### 问题
account-center 启动报错 `could not be registered. A bean with that name has already been defined`，原因：
1. `InfrastructureConfig` 和 `AccountCenterCommonConfiguration` 两个配置类都注册了同名的 `commonExceptionMapper`、`requestIdGenerator` Bean
2. `GlobalExceptionHandler` 和 `AccountCenterExceptionHandler` 两个 `@RestControllerAdvice` 会产生异常处理器冲突

### 修复
1. 删除 `infrastructure/InfrastructureConfig.java`（冗余配置类）
2. 将 `IdempotencyKeyValidator` Bean 合并到 `infrastructure/config/AccountCenterCommonConfiguration.java`
3. 删除 `interfaces/GlobalExceptionHandler.java`（`AccountCenterExceptionHandler` 覆盖面更广）
4. 编译验证通过

## application.yml 改为环境变量配置（完成）

### 问题
远程 MySQL 39.107.95.141:3306 已启动但拒绝 root 从客户端 IP 182.118.232.184 连接（Access denied），导致 DataSource 创建失败 → sqlSessionTemplate 无法注册 → Mapper/Repository/Service 全链路 Bean 创建失败。

### 修复
- application.yml 改为环境变量模式，与 gateway 配置风格一致：
  - `${MYSQL_HOST:39.107.95.141}` — 可通过环境变量覆盖

  - `${MYSQL_USER:root}`

- 用户需在远程 MySQL 上为客户端 IP 授权，或通过环境变量提供正确凭证
