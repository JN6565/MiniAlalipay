### Flyway 迁移表结构验证（T-02 交付条件）
对比 V202608050900__create_credit_tables.sql 与 deploy/mysql/init/00-create-schemas.sql：
- 11 张表的字段、类型、CHECK 约束、唯一键、索引完全一致
- Flyway 迁移正确添加 Schema 前缀（account_db. / ledger_db.）
- Flyway 迁移使用 CREATE TABLE IF NOT EXISTS 保证与 Docker 初始化脚本共存
- FK 约束在迁移中被移除（符合微服务独立迁移最佳实践，AGENTS.md 禁止跨 Schema 外键）
- 初始 Schema 中的 FK 均为同 Schema 内约束，移除后不影响数据完整性（CHECK 约束已保证）

### 技术要点
- 信用表跨 Schema 分布：account_db（3 张表）、ledger_db（8 张表）
- 金额统一使用 long 分，禁止 float/double
- CAS 乐观锁：UPDATE 语句带 version 条件
- MyBatis 注解 SQL，不使用 XML 映射文件
- 还款分配按固定优先级：逾期账单 → 已出账账单 → 未出账消费
- Maven 编译使用 IntelliJ 内置 Maven 3.9.6 + JDK 21
