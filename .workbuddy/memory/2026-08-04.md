### 启动修复
- account-center `application.yml` 中 `characterEncoding=utf8mb4` → `characterEncoding=utf8`
  - 原因：MySQL Connector/J 8.x 驱动不识别 `utf8mb4`（这是 MySQL 服务端字符集名，非 Java 字符集名）
  - 修复：改为 `utf8`，驱动会自动映射到服务端 utf8mb4
